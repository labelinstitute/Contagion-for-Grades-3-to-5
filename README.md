# Contagion

This repository contains the code for the **Contagion Experiment**, developed at the Los Angeles Behavioral Economics Laboratory (LABEL) at the University of Southern California.

The experiment studies decision-making in environments involving contagion risk and was implemented using **oTree** and **Python**.

## Experiment Versions

This repository contains two versions of the experiment:

- **Grade 3–5 version** – adapted for students in grades 3 to 5.
- **K–12 version** – includes the main contagion experiment and additional cognitive and behavioral tasks.
